# PermissionsExPlus

PermissionsExPlus is a maintained fork of the original [PermissionsEx](https://github.com/PEXPlugins/PermissionsEx) (PEX) plugin for Bukkit/Spigot/Paper servers.

The goal of this fork is to keep PermissionsEx usable on modern server environments, preserve the familiar command structure, and continue maintenance for server administrators who still rely on PEX-style permission management.

## Features

- **User and group permission management**: fine-grained control over who can do what
- **Group inheritance and hierarchy**: build permission trees with parent/child groups
- **Prefix and suffix management**: per-group and per-user chat formatting
- **Timed permissions and timed group membership**: temporary access that auto-expires
- **Multi-world permission handling**: world-scoped permissions and options
- **Permission ladder promotion and demotion**: rank-based progression systems
- **Multiple storage backends**: file (YAML), SQL (MySQL/SQLite), H2, or multi-backend
- **Regex-based permissions**: powerful pattern matching for permission nodes
- **Runtime backend switching**: change storage backends without restart
- **UUID support**: full UUID-based user identification
- **Context-aware tab-complete**: all commands support tab-completion with smart suggestions
- **Plugin API**: manage groups, permissions, options, and ladders from other plugins (see the [Developer](/developer/next/overview) tab)
