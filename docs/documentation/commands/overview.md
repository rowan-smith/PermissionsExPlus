# Commands Overview

All commands use `/pex` as the base command. Standalone aliases exist for `/promote` and `/demote`.

Tab-completion is supported for all command arguments, players, groups, worlds, permissions, and subcommands will auto-suggest as you type.

## Command Search

- [Command Search](search): filter the full command list

## Command Categories

- [User Commands](user-commands): managing users and their permissions
- [Group Commands](group-commands): managing groups and their permissions
- [World Commands](world-commands): managing world inheritance
- [Utility Commands](utility-commands): backend, reload, debug, and help
- [Promotion Commands](promotion-commands): rank ladder promotion and demotion

## Syntax Notation

<div class="command-syntax-legend">

| Symbol | Meaning |
|--------|---------|
| `<required>` | A required argument (shown in blue) |
| `[optional]` | An optional argument (shown in orange) |

## Permission Nodes

:::note
Most commands require the `permissions.manage` permission or a more specific node. The full permission node is listed with each command.
:::
